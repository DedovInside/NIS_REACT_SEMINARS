# Непрочитанные сообщения - Practice 7

Семинарское задание по React и интернационализации (i18n).

## Описание

В проекте реализован React-компонент `UnreadMessages`, который:

- при монтировании генерирует случайное число от 1 до 10;
- отображает сообщение вида  
  **"У вас N непрочитанных сообщений"** с корректной плюрализацией;
- выводит дату последнего сообщения (сегодня) в коротком формате  
  `дд ммм чч:мм:сс`.

## Технологии

- React + TypeScript
- react-i18next / i18next
- Intl.DateTimeFormat

## Локализация

- Используется `i18next` с русской локализацией (`ru`)
- Плюрализация реализована через стандартные plural rules i18next
- Формат даты зависит от текущего языка (`i18n.language`)
